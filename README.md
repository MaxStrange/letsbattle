# LetsBattle

**LetsBattle** is a learning project built with the Godot engine. It’s a 2‑D real‑time strategy (RTS) game inspired by *Ogre Battle 64*. Players can control factions of microorganisms battling for dominance inside a mammalian host, while the host’s immune cells act as an opposing force. The game will support local multiplayer (multiple controllers) and a single‑player campaign against AI.

Art style: SNES‑era pixel sprites.

## Features (planned)

- 2‑D RTS gameplay with real‑time combat
- Multiple factions of microorganisms with unique abilities
- Local multiplayer support (multiple controllers)
- Single‑player campaign with AI opponents

## Getting Started

### Prerequisites

- **Godot Engine** (version 4.x recommended) – download from https://godotengine.org
- Git (optional, for cloning the repo)
- A code editor

### Clone the repository

```bash
git clone https://github.com/MaxStrange/letsbattle.git
cd letsbattle
```

### Open the project in Godot

1. Launch Godot.
2. Click **Import** → select the `project.godot` file inside the repository.
3. Open the project and press **Play** to run the current prototype.
